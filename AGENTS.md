# Tech One-Stop Solution Ltd — Website

Corporate website for Tech One-Stop Solution Ltd (TOSS), built with TanStack Start, React and Tailwind CSS.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Notes

- Keep the branch in a working state before pushing.
- Site content lives in `src/content/site.ts`.
- Pages live in `src/routes/`.
